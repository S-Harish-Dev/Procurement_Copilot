# ADR-16: Deployment: Docker Compose locally, a native stack for load tests and drills, CI via `make ci`

- Status: accepted (2026-10-30)

## Decision
- Laptop: `infra/docker-compose.yml`: postgres, qdrant, valkey, opa, otel-lgtm, prometheus, mailpit, gateway,
  brain, mcp-procurement, mcp-notify, and (profiles `offline`/`loadtest`) mock-llm, mock-llm-2, mock-jev. Every port
  is bound to 127.0.0.1. The images build and the stack runs on a laptop with Docker Desktop; the UI was tested against it.
- Native stack (no Docker): `scripts/native-stack.sh start|stop|status|restart-gateway|
  restart-python` runs the same versions as native user processes (Postgres 18.6, Valkey 9.1.3, Qdrant 1.20.0,
  OPA 1.22 with `--watch`, Mailpit 1.32, Prometheus 3.15.1, Grafana 13.3.0, mocks). Postgres uses SCRAM and Valkey
  `requirepass`, because other users of a shared machine can reach localhost.
- Heavy work stays on the build machine: `make build-index` produces a checksummed bundle (`data/index_bundle`:
  177 documents and 11,322 chunks in the full build; the committed copy has 175 documents, 10,356 chunks and the nomic-v1.5 vectors); the laptop only runs `make ingest` (no model inference).
- CI: `make ci` (fmt, clippy `-D warnings`, cargo tests, ruff, mypy, pytest, OPA tests, web lint/typecheck) is
  mirrored by `.github/workflows/ci.yml`; nothing is pushed.
- Secrets only in `.env` (gitignored, generated by `make env`), `.env.example` committed.

## Why
My laptop is too weak to embed the corpus, so the heavy work runs on a bigger machine and a bundle carries the result. Compose and the native stack use the same service versions, which keeps both reproducible.

## Limits
Free container hosts can't run this stack (e.g. Render's 512 MB), so there is no public hosting: local Compose plus a
recorded video. The Grafana provisioning inside otel-lgtm is still unverified. Kubernetes (HPA on the gateway, StatefulSets for Qdrant/Postgres) is the documented next step.

## Alternatives rejected
- *Kubernetes now*: operational weight with no cluster to run it on.
